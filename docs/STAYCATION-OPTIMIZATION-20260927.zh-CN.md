# Staycation 延迟优化与重新录制

2026-09-27。沿用原句“在小红书上查找总结最近适合staycation的地方”，不限定城市。两种方案都使用同一优化后的执行框架，先录 Jev + DS，再录纯 DS。

## 实现变化

1. **并行准备连接**：新增 `--preconnect`。在浏览器启动时，通过后续模型调用使用的同一 HTTPX 客户端访问模型服务根地址。GET 不带 API key、不触发模型推理，失败不阻止正常调用。准备时间计入端到端，另存 `network-preconnects.jsonl`。401/404 表示 HTTP 可达，不视为模型失败。
2. **搜索读回宽限时间**：新增 `AgentTuning.search_readback_grace_s`，默认 3 秒。重复 pending 达到原触发次数后，给页面正常加载留出时间；仍保留等待次数上限及必要复核，不重复提交搜索。
3. **精简最终复核输出**：`FinishReview` 保留最终答案、完成判断、证据与阻塞说明，不要求重复生成 working_memory。完整来源归档与新观察仍进入复核，完成与引用校验保持原标准。兼容旧式反馈输出，避免合法的 working_memory 字段触发额外修复。
4. **补齐启动埋点**：记录调试入口发现、Playwright 启动、CDP 连接、新标签页、配置、初始导航及收尾。`browser.setup` 是父 span，不与其子项重复相加。

重复输入缓存仍遵守原来的来源与目标一致性条件。本轮没有通过放宽缓存或 DOM 绑定来跳过检查。

## 测试

针对模型传输、输入绑定、最终复核、搜索读回、Chrome 会话、浏览器效率、观测与研究配置执行回归测试。首轮 123 项通过，发现 1 处新旧最终反馈 schema 兼容问题；改为兼容解析后，该用例和新最终复核用例复验通过。新增测试覆盖：无认证预连接及账本隔离、预连接失败后的正常调用、保留最终证据、短暂 pending 宽限及有界复核。Ruff 与 git diff 检查通过。

## 与优化前 Jev + DS 成功轮相比

| 指标 | 之前 | 新一轮 |
| --- | ---: | ---: |
| 端到端 | 59.1808 秒 | 37.6174 秒 |
| 控制循环 | 33.4081 秒 | 30.8159 秒 |
| 循环外准备与收尾 | 25.7727 秒 | 6.8014 秒 |
| Jev 请求 | 7 次，6.3741 秒 | 12 次，5.6525 秒 |
| 首次 Jev 请求 | 3.5364 秒，含 3.0867 秒 TLS | 约 0.425 秒，复用连接 |
| DS 搜索读回指导 | 1 次，5.5257 秒 | 0 次 |
| DS 最终复核 | 10.7694 秒 | 11.1146 秒 |
| API 等价费用 | $0.015478554 | $0.017408988 |

端到端少 21.56 秒（36.4%），控制循环少 2.59 秒（7.8%）。**最大差额来自准备与收尾变化，不能把全部降幅归因于代码优化。** 新轮浏览器 setup 为 6.54 秒，此前该段没有完整埋点，网络状态也不同。单独启动探测曾测得 15.38 秒，其中 CDP 连接 7.85 秒、导航 6.73 秒，说明启动抖动很大。

新轮的 16 次模型请求全部成功、全部返回 usage，模型请求中没有重新建立 TLS。12 次 Jev 请求平均约 0.471 秒。原轮只有 7 次 Jev 请求，新轮增加了滚动阅读，成本反而增加约 12.5%。最终复核输出从 2,657 token 降至 2,275 token，但输入内容更多，耗时并未下降。不能把精简 schema 当作已验证的最终总结加速。

本组数值表现为 Jev + DS 少 53.85 秒，费用为纯 DS 的约 0.38 倍。但两者检索词和阅读范围不同，不作为等质量的架构加速结论。

纯 DS 搜索“最近适合staycation的地方”，主要整理站点 AI 摘要并打开一篇笔记，回答包含嘉佩乐、安达仕与璞丽体验。Jev + DS 搜索“staycation 推荐”，滚动阅读结果页，主要依据 AI 摘要与标题，回答包含前滩华尔道夫、国家会展中心洲际、长兴岛宋品等。两者均未独立核验实时价格、可订性或所有推荐的最近性。站点的“46 篇 / 62 篇”是站点 AI 摘要标注，不是 agent 的实际阅读篇数。

纯 DS 有一次 initial 阶段输出多余 `type` 字段，触发严格 schema 修复。后期几次生成式动作决策分别用了 13.40、8.68、5.13 秒，11 次策略请求合计 47.97 秒。新轮开销差异同时受搜索内容、笔记正文、生成长度和模型时延影响。

## 失败与准备开销

第一次 Jev 补录在小红书首页导航遇到 `net::ERR_CONNECTION_CLOSED`，14.8809 秒后结束，模型调用 0 次。失败记录没有删除。包括这次失败，新一轮 Jev 总投入 52.4983 秒，模型 token 费用仍为 $0.017408988。

预连接每轮各有 2 条未认证 GET，单列在 `network-preconnects.jsonl`，不计作模型推理请求或虚构 token 用量。其耗时已计入端到端并与浏览器准备重叠，不应再叠加一次。诊断探测与视频编码时间不计入 task 的模型成本或任务耗时。

费用使用 2026-09-27 周日 off-peak：DS 未缓存输入 $0.15/M、缓存输入 $0.003/M、输出 $0.60/M；Jev 输入 $0.042/M，输出免费。按 API 返回的缓存拆分计算，非账户账单。价格来源为 https://api-docs.deepseek.com/quick_start/pricing/ 与 https://docs.typesafe.ai/models 。
